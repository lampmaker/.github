# .github

Default files for every repository under [lampmaker](https://github.com/lampmaker). GitHub uses a file from here for
any repository that has no file of that kind of its own; a repository's own file always wins.

| File | What it does |
|---|---|
| [`FUNDING.yml`](FUNDING.yml) | The ♥ **Sponsor** button, leading to [github.com/sponsors/lampmaker](https://github.com/sponsors/lampmaker). A repository shows it once *Settings › General › Features › Sponsorships* is ticked there. |

This repository has to stay **public** for GitHub to use these defaults.

The profile page's README is not this one: it lives in [lampmaker/lampmaker](https://github.com/lampmaker/lampmaker).

## Why sponsor?

I'm building [ShadyTracer](https://github.com/lampmaker/ShadyTracer), physically based light in the browser: a WebGPU
path tracer in real units, with a scene builder and an optics bench for LED and luminaire design. It's free, and I want
it to stay free for students, makers, artists and anyone curious about light. A tip, one-time or monthly, keeps it
going: **[♥ Sponsor](https://github.com/sponsors/lampmaker)**.
